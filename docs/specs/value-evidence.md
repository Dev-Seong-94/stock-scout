# Spec: 싸 보이는 후보 찾기 → 근거 확인

상태: 승인됨 (2026-11-05)

## 목적

"뭐 괜찮은 거 없나?" 하고 스크리너를 연 초보자가 조합을 고민하지 않고 후보를 좁히고,
종목 페이지에서 "이 조건에서는 싸고, 하락은 주로 이런 이유로 보인다"라고 직접 말할 수 있게 해요.

- **사용자:** 주식 발굴을 처음 하는 본인 (사용자 한 명)
- **완료 모습:** 스크리너를 열고 몇 분 안에 후보 하나를 골라 근거를 말할 수 있어요.
- **앱의 역할:** 사실과 계산 결과를 보여 줘요. 판단은 사용자가 해요.

## 기능

### 1. 스크리너: 조건 충족 개수

"싼가" 조건 3개의 충족 개수를 결과 표에 보여 주고, 많이 충족한 순서로 정렬할 수 있어요.

| 조건 | 충족 기준 | 확인 불가 |
|---|---|---|
| 업종 대비 | PER이 같은 섹터 하위 40% 이내 (`pe@sector` ≤ 40) | PER ≤ 0, 부동산 섹터, 유효 값이 5개 미만인 섹터 |
| 자기 과거 대비 | 현재 PER이 자기 과거 중앙값보다 낮음 | 최근 회계연도 적자, 주간 값 26개 미만 |
| 현금 기준 가치 | 현재가가 기본 시나리오 계산값보다 낮음 | FCF ≤ 0, FCF 없음, 금융 섹터 |

- 표시는 `2 / 3`처럼 **충족 개수 / 확인 가능한 조건 수**예요. 확인 불가는 불충족과 구분해요.
- 정렬은 충족 개수 → 확인 가능한 조건 수 → 시가총액 순이에요. 얼마나 싼지로 줄 세우지 않아요.
- 시작 화면 맨 앞에 "가치보다 싸 보이는 후보 찾기"를 둬요. 기존 예시 조합은 그대로 남겨요.
- 표 위에 안내해요: "개수는 점수가 아니라 먼저 확인해 볼 순서예요. 싼 데는 이유가 있을 수 있어요."

### 2. 종목 페이지: "싼가?"

"한눈에 보기" 바로 아래에 조건별 사실을 보여 줘요.

```
싼가?                                    스크리너 데이터 11/5 기준
· 업종 대비      PER 14배 / 섹터 중앙값 22배 / 섹터 하위 18%   → 낮은 쪽
· 자기 과거 대비  PER 14배 / 2022년 이후 중앙값 19배           → 낮은 쪽
· 현금 기준      계산값 $92 ~ $132 ~ $190 / 현재가 $100        → 기본 계산값보다 낮음
```

- 값이 없으면 이유를 적어요. 예: "최근 회계연도가 적자라 PER로 비교할 수 없어요."
- 세 줄과 스크리너의 개수는 같은 스냅샷, 같은 함수로 계산해서 항상 일치해요.

### 3. 현금 기준 가치 계산

현재 FCF로 앞으로 벌 현금을 현재 가치로 바꾼 값이에요. 회사별 전망을 넣지 않고 모든 종목에 같은 가정을 써요.

| 시나리오 | 10년간 FCF 성장 | 할인율 | 이후 영구 성장 | FCF 배수 | 현재가와 같아지는 FCF 수익률 |
|---|---|---|---|---|---|
| 낮게 | 0% | 10% | 2.5% | 11.4배 | 8.8% |
| 기본 | 5% | 10% | 2.5% | 16.4배 | 6.1% |
| 높게 | 10% | 10% | 2.5% | 23.7배 | 4.2% |

- 계산식: `계산값 = 현재가 × FCF 배수 × FCF 수익률 / 100`. 스냅샷의 `fcf_yield`만 있으면 돼서 요청이 늘지 않아요.
- 가정을 항상 화면에 같이 적어요.
- "목표가가 아니에요. 가정을 바꾸면 크게 달라져요."라고 밝혀요.
- 경기민감주처럼 최근 FCF가 평소와 다를 수 있는 한계도 적어요.

### 4. 종목 페이지: "왜 떨어졌나?"

"싼가?" 바로 아래에 보여 줘요. 원인을 단정하지 않고 비교만 해요.

```
왜 떨어졌나?
              1개월    3개월    6개월    1년
이 종목        −8%     −25%    −30%   −35%
섹터(XLK)      −3%     −18%    −15%    −5%
S&P 500       −1%      −9%     −4%    +6%

회사 실적 (최근 분기, 전년 같은 분기 대비)
· 매출 +8% · 영업이익률 21% (전년 22%) · 희석 주식 수 +1%
```

- 표 아래에 사실 한 줄을 고정 규칙으로 붙여요. 예: "3개월 동안 섹터보다 7%p 더 떨어졌어요."
- 실적이 눈에 띄게 나빠졌을 때만 사실로 짚어요. 예: "매출이 전년 같은 분기보다 줄었어요."
- "회사 문제가 없어요", "시장 탓이에요"처럼 판정하는 문장은 쓰지 않아요.
- 이 구간에 오르기만 했다면 "이 기간에는 떨어지지 않았어요"라고 적어요.
- 끝에 다음 단계로 최근 10-Q·8-K 공시를 안내해요.

## 코드 스타일

기존 `indicators.py`, `valuation.py`처럼 네트워크 없는 순수 함수로 쓰고, 값이 없으면 `None`을 돌려줘요.

```python
def cash_value_multiple(growth: float, discount: float = 0.10, terminal: float = 0.025, years: int = 10) -> float:
    """Value of a stream of free cash flow, as a multiple of today's FCF."""
    near = sum(((1 + growth) / (1 + discount)) ** t for t in range(1, years + 1))
    far = (1 + growth) ** years * (1 + terminal) / (discount - terminal) / (1 + discount) ** years
    return near + far
```

## 테스트 전략

`backend/tests/test_core.py`에 오프라인 pytest로 추가해요. 프론트엔드는 타입체크, 빌드, 브라우저 확인으로 검증해요.

- FCF 배수가 위 표의 값(11.4, 16.4, 23.7)과 맞아요.
- 조건마다 충족, 불충족, 확인 불가를 구분해요.
- 적자 기업, 금융주, 부동산, FCF 음수, 짧은 상장 기간의 확인 불가 이유가 맞아요.
- 정렬에서 확인 가능한 조건이 적은 종목이 앞서지 않아요.
- 고정 문장 규칙이 판정 표현 없이 사실만 만들어요.

## 경계

- **항상:**
  - 판단 표현 없이 사실과 가정만 써요.
  - 값의 기준 날짜를 표시해요.
  - 지표는 `metrics.py`에 한국어 설명과 함께 정의해요.
  - `pytest -q`, 타입체크, 빌드를 통과시켜요.
- **먼저 물어보기:**
  - 새 의존성 추가
  - 조건 기준이나 계산 가정 변경
  - 기존 예시 조합 제거
  - 시장 상태에 따라 후보를 다르게 보여 주는 기능
- **하지 않기:**
  - 매수·매도 추천, 목표가, 종합 점수, 등급
  - "싸다", "문제없다" 같은 판정 문장
  - 성장주·추세 흐름, 테마 탐색
  - 뉴스를 읽고 하락 원인을 단정하는 것
  - AAII 403 우회, 비밀값 커밋

## 성공 기준

1. 시작 버튼 한 번으로 조건 충족 순서의 후보 목록이 나와요.
2. 같은 종목의 개수와 "싼가?" 세 줄이 항상 일치해요.
3. 확인할 수 없는 조건에는 모두 이유가 적혀 있어요.
4. 계산값 옆에 가정과 "목표가가 아니에요" 문구가 항상 있어요.
5. "왜 떨어졌나?"에 종목·섹터·S&P 500의 4개 기간 비교와 최근 분기 실적이 나와요.
6. 새 화면 문구에 매수·매도, 목표가, 추천, 저평가 확정 같은 표현이 없어요.
7. 전체 스냅샷 재생성 후 `pytest -q`, 타입체크, 빌드를 통과하고 모바일(375px)에서 가로로 넘치지 않아요.

## 재생성 비용

전체 스냅샷을 한 번 다시 만들어야 해요 (80~100분 예상). 가격 기간을 5년으로 늘려서 일괄 다운로드가 더 오래 걸릴 수 있어요.
종목별 요청 수는 그대로예요. 연간 실적은 이미 받고 있어요.

## 결정 사항 (2026-11-05 승인)

1. **현금 기준 가정:** 모든 종목에 고정 시나리오(0/5/10%)를 써요. 회사별 성장률은 쓰지 않아요.
2. **업종 대비 기준:** PER 섹터 하위 40% 이내예요.
3. **달러 계산값:** 달러 범위로 보여 주고, 가정과 "목표가가 아니에요" 문구를 항상 붙여요.
